# Frozen release reproduction evidence

The [one-command bootstrap](../../Scripts/bootstrap_reproduction.sh) downloads verified release assets, installs isolated Python 3.13.0 with pinned dependencies, and performs a fresh offline rebuild plus reference comparison. See [instructions](../../Documentation/reproduce_release.md).

The pre-publication relocated rebuild passed all 313 acceptance checks. Every scientific value and dtype matched across the 157,160 x 665 master, 157,160 x 157 bridge, and 141,038 x 1,312 UNITID panel. The master is byte-identical; only explicitly named HD/CW provenance path directories are normalized for linked-file comparisons. [reproduction_report.json](reproduction_report.json) and [reproduction_log.txt](reproduction_log.txt) preserve the actual run evidence and wrapper hash. The original run used a 371-file bundle; final packaging adds the transitive environment lock and includes the hardened runner. [final_bundle_verification.txt](final_bundle_verification.txt) verifies the final 372-file bundle and original selected source bytes. A complete public-bootstrap run is verified separately after publication.

An independent rebuild of the final 372-file bundle completed on September 23, 2026 in 565.47 seconds with the shipped runner (`ee6417bc1a00efc700a4a934c594fdf15cb691dc839b4e1c58d4628ccb5d094a`). All 86 selected FSA inputs passed integrity verification, all 313 acceptance checks passed, and all three reference-panel comparisons passed with the same path-only normalization described above. [final_packaged_reproduction_report.json](final_packaged_reproduction_report.json) and [final_packaged_reproduction_log.txt](final_packaged_reproduction_log.txt) preserve this completed offline run.
